# Security policy

Only the current 5.3.x release line receives security fixes. Do not publish a
security-sensitive report as a normal issue. Use GitHub's private vulnerability
reporting feature when it is enabled for the repository. Otherwise contact the
repository owner privately through the contact method shown on their GitHub
profile.

Include the affected version, operating system, reproduction steps and likely
impact. Do not include passwords, tokens, personal data or another player's save.
