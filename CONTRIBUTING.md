# Contributing

Small, focused contributions are welcome.

1. Open an issue before beginning a large gameplay or save-format change.
2. Create a branch, keep unrelated changes separate and preserve old saves and
   legacy challenge-code replay.
3. Run `python -m unittest discover -s tests` before opening a pull request.
4. For interface or art changes, run the verified preview command described in
   `WINDOWS_RELEASE.md` and include before/after screenshots.
5. Do not submit copied game assets, music, dialogue or source code. Contributions
   must be original or have clearly documented redistribution permission.

Pull requests should explain player impact, testing performed, save compatibility
and any comfort/accessibility effects.
