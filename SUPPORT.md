# Support

Before reporting a problem:

1. Confirm the title screen shows version 5.3.1.
2. Extract the complete ZIP into a new writable folder.
3. Keep the executable's `_internal` folder beside it.
4. Try Settings > Troubleshooting and export a support report.
5. For controller problems, open Settings > Controls and record the device name
   plus which inputs appear in INPUT TEST.

Open a GitHub issue using the bug-report form. Include Windows version, keyboard
or controller model, USB/Bluetooth connection, exact reproduction steps and the
support report. Review `last_error.txt` before attaching it. Do not post private
information or your save database publicly.
